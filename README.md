
# FashionIQ – Smart Fashion Recommendation Platform

FashionIQ is an AI-powered fashion discovery platform that provides personalized clothing and outfit recommendations based on user preferences and browsing behaviour.

## Technology Stack

- Frontend: Next.js, React, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MySQL
- Vector Database: ChromaDB
- Recommendation Engine: Python
- Version Control: Git and GitHub
